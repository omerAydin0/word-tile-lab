Release-reviewer eval

word-tile-lab · the reviewer is the level team's last gate

The reviewer reads the designer's, curator's and analyst's reports and checks every number against tool output. Each case below gives it real tool output for a campaign and reports with one planted defect - or none. A defect only counts as caught when the reviewer fails the campaign and names the right report (and level). Clean cases test the opposite failure: rejecting sound work. Model: Sonnet, the production model · dev split · 3 runs per case.
